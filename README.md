# RELAR TRAVEL

Англоязычная демонстрационная коллекция путешествий. Шесть страниц, семь направлений и 14 вымышленных маршрутов. Цены указаны в долларах США за человека. Все заявки обрабатываются в браузере.

## Как открыть

Откройте index.html в современном браузере с включённым JavaScript. Сборка и установка зависимостей не требуются. Фотографии включены в проект. Шрифты DM Sans и Playfair Display загружаются из Google Fonts, при отсутствии сети используются системные шрифты.

## Публикация на GitHub Pages

1. Загрузите HTML-файлы и папки assets, css и js в корень репозитория GitHub, сохранив структуру.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, укажите ветку с файлами и папку **/(root)**, затем нажмите **Save**.
4. После завершения публикации откройте ссылку **Visit site** в настройках Pages.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Устройство проекта

Главная страница передаёт выбранные параметры поиска в каталог. Каталог поддерживает поиск по названию, сортировку по цене и фильтры. Ссылки на маршрут используют параметр id, например [Maldives Lagoon Retreat](tour.html?id=lagoon-days). Переход к заявке подставляет выбранное направление и название тура.

- **js/data.js** содержит направления, маршруты, длительность и демо-цены.
- **js/main.js** отвечает за страницы, меню, каталог и форму.
- **css/style.css** содержит общие стили, адаптивную сетку и настройки анимации.
- **assets/** содержит фотографии, логотип для вкладки и [ссылки на оригиналы фотографий](assets/credits.md).
